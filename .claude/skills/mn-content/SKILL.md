# Content rules (Morellonomicon)

Reader text is Traditional Chinese with Taiwan wording and the official zh_TW client names. Read the note right before editing it.

- **Frontmatter keys you may add by hand:** champions `video` (YouTube id), `pinned`, `avoid`, `archetypes_extra`, `features_extra` (tags the skill text cannot show), `positions` (lanes in zh_TW, e.g. `["中路", "上路"]`; overrides the counted lanes), `punch` (速查's one-line character overview, keywords not an ability, e.g. 免控黑盾，定人定三年), `soul` (how to play it: a line, or a list of two or three lines, 速查's 玩法 tab), `stack` (the stats to build towards, names from `STAT_ICON` in `plugin/src/ui.ts`), `focus` (Q / W / E / R / P, only when one ability is the point), `picks_status` (待驗證 / 已驗證: the 速查 text was proofread; set in `Inbox/速查卡片.md`), `face` (CSS object-position of the face in the loading art, e.g. `50% 20%`); `skins` is generated (skin numbers without chromas), `plain` (`{"P": …, "Q": …}`: each ability in plain words, one short line), `aliases` (nicknames people say, e.g. `["機器人"]`; 速查 finds the champion by them, as text and by sound), `onhit` (keys of the abilities that apply on-hit effects, e.g. `["R"]` for Katarina; lights 攻擊特效 and shows 觸發攻擊特效 on those abilities); augments `effect` (zh_TW, numbers included) with `effect_source` (e.g. League of Legends Wiki), `effect_patch`, `effect_status` (待驗證 / 已驗證), `fits`, `tier`, `combos`. The fetch scripts keep them on a rerun. `python3 -I tools/fetch_augments.py` makes the Mayhem augment notes (CommunityDragon needs a User-Agent; there is no effect text, so do not make one up). Run it from the repo root: `python3 -I tools/fetch_data.py [--only Ahri,Garen]`.
- **Tips and builds (hand-written, in a champion note's frontmatter).** `tips: [{title, text, video, patch, date, source, source_name, status}]` and `builds: [{kind: meta|alt|synergy, mode: mayhem|rift, name, items: [item ids], note, with: [champion ids], patch, date, source, source_name, status}]`. `patch` and `date` are required for every entry (the app warns when the patch is older than the data's); `status` is 待驗證 or 已驗證. Items are ids from the item notes; check each is in the mode's pool. Patches may be written as 26.21 or 16.21 (the same patch). Credit the source and link it; put another creator's idea in our own words, never copy a transcript.
- **Inbox.** `Inbox/技巧.md` (tricks) and `Inbox/玩法出裝.md` (a champion's Mayhem builds: champion, 玩法, 核心 1–3 items, 怎麼玩; read as it is by `tools/build_tiers.py`, not processed away; rerun the script after a change, [[Build Model]]) are where Zaviel drops rough notes, through an editor like the Layouts note: a ```mn-inbox block holds the entries as JSON (`{"kind": "tip" | "build", "entries": [...]}`, one entry per line; `plugin/src/inboxnote.ts`), drawn as cards with a form (champions and items are picked from lists with their pictures, `plugin/src/pickers.ts`). `Inbox/速查卡片.md` is an editor of the 速查 keys (`punch`, `stack`, `soul`, `focus`, `plain`, `picks_status`) straight in the champion notes (`plugin/src/picksnote.ts`). "Process the inbox" = turn each entry into a tip / build as above in zh_TW, check item names, keep source / patch / date, show the result before committing, then remove the entry from the block. Zaviel's own patch notes go in `版本更新/` (frontmatter: title, patch, date, summary).
