## 🎛️ Cleaner Champions header and icon tags (Claude, for Zaviel)
- The "Mayhem" chip under the title is gone; the colour and mode buttons now sit on the same line as the big tab title.
- Ability tags are icons only (控場 hand, 緩速 snowflake, 位移 arrows, 治療 heart, 護盾 shield, 吸血 drop, 強化普攻 swords); lit = has it, dim = does not. Tap an icon for its name.
- The ? icon opens a chart with each icon's name, English name, abbreviation and meaning.

## 🏷️ Truer champion tags, 速查 moved to Champions (Claude, for Zaviel)
- 速查 now sits at the top of the Champions tab instead of the Handbook; the Handbook is only for reading.
- A champion shows every damage kind it deals: the main one as 物理輸出 / 魔法輸出 and the others as 兼物理 / 兼魔法 (Katarina: 魔法輸出 + 兼物理).
- More skills count as 位移 (瞬步, 閃爍, 瞬移, 衝向, 翻滾, 往後退 ...): Katarina and Caitlyn now have it.
- New 強化普攻 pill and filter for champions whose skills change basic attacks (next attack, extra damage on attack). It is read from the skill text, so it is wider than "builds on-hit items".

---
## 📱 Vault at the repo root (Zaviel)
- The repo folder is now the vault, so the phone can clone it with Obsidian Git and get the notes, theme, snippets and the Morellonomicon plugin in one go.

## 🧩 Everything in one app (Zaviel)
- Augments, items, guide cards and patch notes open as pages inside the app, with Back, instead of jumping to an Obsidian note.
- "Show all" on the Patch tab is a full page with a card per champion, item or augment.
- Filter panel, chips and the sub-tab bar were redesigned after phone screenshots.

## 📰 Riot's patch notes in the Patch tab (Zaviel)
- The Patch tab shows the latest official patch (headline image, Riot's blurb, a link) and in short what changed: Mayhem's new and removed augments with their effect text, champions and items with the numbers before and after.
- New augments now show their effect in the augment list.
- One command updates everything for a new patch.

## 🔁 What changed since the last patch (Zaviel)
- A champion changed this patch shows a ▲ / ▼ badge; changed cooldowns, costs and ranges turn green or red with the old value struck through; a "Recent changes" block lists the last few patches, and the Patch tab lists everyone changed this patch.

## 🧭 Simpler app and real build data (Zaviel)
- Three tabs now: Champions, Augments, Learn. A champion has Skills, Build, Augments and Tips; one search box finds champions, augments and items.
- Build shows what players really buy (once match data is collected), our fun alternative builds and builds for playing with a teammate; tapping an item shows its effect. Tips holds hidden tricks.
- Handbook is six short beginner cards.

## ✨ Mayhem augments and a prettier card (Zaviel)
- All 249 Mayhem augments are in the vault with Traditional Chinese names, rarity (銀 / 金 / 稜鏡) and icons, and the app lists them with search and a rarity filter.
- The champion card shows a radar chart and a splash-art banner; the whole app got a softer, more modern look.

## 🧩 Plugin shell (Zaviel)
- A Morellonomicon screen inside Obsidian: pick your champion from an icon grid and see everything on one card, with almost no text.
- Tabs Mayhem · Champions · Items · Guide; a mode switch is in place for Summoner's Rift, which stays "coming soon".
- Champion notes now fold their long text into collapsed boxes.

## 📚 Champion and item notes (Zaviel)
- `tools/fetch_data.py` generates a note for all 173 champions and 372 items in Traditional Chinese: stats, skills with damage types (物理 / 魔法 / 真實), Riot's own tips, icons.
- Each champion gets automatic archetypes and features (控場, 治療, 護盾, 位移); ARAM-only item versions link to the base item.
- Your own advice goes below the end marker and survives a rerun.

- Solo project: dropped `CONTRIBUTING.md`, the PR template and `CODEOWNERS`; changes are committed straight to `main`.

## 🎨 Vault look (Zaviel)

## 🌱 Project start (Zaviel)
- Morellonomicon (黑魔禁書): a Traditional Chinese LoL guide for beginners, as an Obsidian vault that opens on a phone, with a focus on ARAM Mayhem augments.
- Decided on a vault, not a C desktop app. Data comes from Riot Data Dragon (`zh_TW`) and CommunityDragon.
