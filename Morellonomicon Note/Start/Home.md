**黑魔禁書 (Morellonomicon)** 是給英雄聯盟新手的繁體中文攻略筆記:英雄定位、技能傷害類型、各模式的出裝思路,以及**隨機單中 大混戰(ARAM Mayhem)** 的強化選擇與強力組合。

> [!tip] Start here
> 1. [[Start Guide]]: set up, open on phone, the daily loop.
> 2. [[Dev Status]]: where things stand; [[Dev Log]]: what changed, day by day.
> 3. [[LLM Guide]]: the map and rules for AI assistants.

## 🗂️ What is where

| Folder | What |
| --- | --- |
| `Start/` | this page, [[Start Guide]], [[LLM Guide]] |
| `Review/` | [[Dev Status]], [[Dev Log]], `Log/<year>/<month>/<week>/` (one note per day) |
| `新手入門/` | beginner guide: roles, damage types, item logic |
| `英雄/` | one note per champion (generated by `tools/fetch_data.py`, your advice below the end marker) |
| `道具/` | one note per item, with the ARAM versions |
| `強化/` | ARAM Mayhem augments by type, which champions fit, combos |
| `模式/` | Normal, Ranked, ARAM, ARAM Mayhem |
| `_Meta/` | vault helpers: Templates |

## ✍️ Writing here

- No `# Title` inside a note: the file name is the title.
- Reader-facing content is Traditional Chinese; workflow notes are English.
- Link champions, augments and items with `[[ ]]` so backlinks show what fits what.
