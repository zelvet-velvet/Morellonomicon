# Vellum

Screens laid out on a phone with the Vellum plugin ([github.com/zelvet-velvet/vellum](https://github.com/zelvet-velvet/vellum)). Reading view: the card shows the screen map; **Open editor** opens the editor (its own window on a computer, the full screen on a phone).

Every page of the app as it is, captured from the running app (390 × 844, an iPhone 14) into the blocks of [[Layouts]]: real pictures by address, Lucide icons, text. The champion pages use Katarina. **Home · linked** and **最近對戰** are drawn from sample data (the real pages need a linked Riot ID). **Handbook · card** is the card frame (text limits in its block notes); the **Card · …** screens inherit it and show one stage template each.

Agents: one file per screen in `Dev Tools/Vellum/` (blocks one per line); read only the screen you work on.

```vellum
src: Dev Tools/Vellum
```
