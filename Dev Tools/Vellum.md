# Vellum

Screens laid out on a phone with the Vellum plugin ([github.com/zelvet-velvet/vellum](https://github.com/zelvet-velvet/vellum)). Reading view: the card shows the screen map; **Open editor** opens the editor (its own window on a computer, the full screen on a phone), **New screen** adds the first one. Agents read the JSON below: one screen per line.

```vellum
{"id": "morellonomicon", "device": "iphone-16-pro", "pages": [
]}
```
