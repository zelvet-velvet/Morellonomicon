# Morellonomicon 黑魔禁書

給英雄聯盟新手的繁體中文攻略筆記庫(Obsidian vault),重點是**隨機單中 大混戰(ARAM Mayhem)**:哪些英雄適合哪類強化、有哪些強力組合。也涵蓋英雄定位、技能傷害類型,以及不同模式(一般、積分、ARAM)的出裝思路。

A Traditional Chinese League of Legends beginner guide, kept as an Obsidian vault that opens on a phone. Focus: ARAM Mayhem augments and strong combos.

## 使用 / Use

1. Install [Obsidian](https://obsidian.md) (PC or phone).
2. Open the folder `Morellonomicon Note/` as a vault.
3. Plugins are not stored in git. Run `python3 tools/install_plugins.py`, then turn off Restricted Mode in Obsidian.
4. On a phone, sync the vault with Obsidian Sync, iCloud, Syncthing or Git.

## 資料來源 / Data

Champion, skill and item data come from Riot's public [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon) (`zh_TW`) and [CommunityDragon](https://www.communitydragon.org/). Every generated page shows the patch it was made from.
