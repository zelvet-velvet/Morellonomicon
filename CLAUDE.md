# Morellonomicon

黑魔禁書: a Traditional Chinese League of Legends beginner guide (focus: ARAM Mayhem augments), kept as an Obsidian vault. Read `Morellonomicon Note/Start/LLM Guide.md` first (map, rules, repo regulation, `CMD_SYNC`), then `Morellonomicon Note/Review/Dev Status.md` for what is built and what is pending.

**Zaviel** (GitHub `zelvet-velvet`) is the owner; everyone else is a contributor. Find out whom you are working with from `git config user.name` (ask if unsure) and follow `CONTRIBUTING.md`:
- Work on a `type/slug` branch off `main` and open a pull request; never push to `main`, never merge a PR on your own judgement: Zaviel merges. You may merge a PR when Zaviel says in the conversation that they checked it and it is ready (a merge commit, then delete the branch).
- Visual changes (theme, CSS) start with a rendered picture that Zaviel picks.
- Each PR: a Dev Log entry with the author's name, pictures for visual changes.
- Commit with the user's own git identity (set in the repo, not globally).
- Vault content for readers is Traditional Chinese; workflow notes stay English.
