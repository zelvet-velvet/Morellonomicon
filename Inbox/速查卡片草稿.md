Drafts for the 速查 cards, written by Claude from memory of how each champion plays (not from a data source), so **check every line**. Edit in place; nothing reads this note yet. Once it is right, a script will copy it into each champion note (`punch`, `soul`, new key `focus`).

- **主力**: the one ability to use and abuse (shown super highlighted on the 技能 tab). Q / W / E / R, or P.
- **一句話** (`punch`): what the champion is, in keywords, ≤ 14 字.
- **靈魂** (`soul`): the one thing that makes it work, ≤ 16 字 (it sits on the card's tip line).
- `(待補)`: I did not know the champion well enough; fill it in. The later half of the list is rougher than the first: read it with more doubt.
