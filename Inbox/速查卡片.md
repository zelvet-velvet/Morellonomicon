> [!abstract]+ 速查 cards, edited in the champion notes
> The text of the 速查 cards lives in each champion note's frontmatter (`punch`, `stack`, `soul`, `focus`, `plain`). Pick a champion below and edit; a field is written into that note when you leave it. **下一位待驗證** jumps to the next champion not yet checked; set **已驗證** once a champion's text is right (`picks_status`). The first drafts (Claude, from memory of how each champion plays) are in the git history of this note.

> [!info]- What each field is
> - **一句話** (`punch`, tab 1): what the champion is, in keywords, ≤ 14 字.
> - **堆** (`stack`, tab 2 chips): what to build towards, two or three from this list only: 法術強度 攻擊力 攻速 技能急速 暴擊 生命 護甲 魔防 穿透 跑速.
> - **玩法** (`soul`, tab 2): how to abuse the champion, two or three lines, ≤ 16 字 each, one per box in the editor.
> - **技能白話** (`plain`, tab 3): each ability in plain words, one short line.
> - **主力** (`focus`, optional): only for a champion whose one ability is the point (stacking, a quest, the hook). Most have none: leave it empty.
